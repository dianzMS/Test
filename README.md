## What Can GitHub Copilot Coding Agent Do?

GitHub Copilot Coding Agent is an AI-powered assistant that can help you with a wide range of software development tasks directly in your repository:

### 🛠️ Code Changes
- **Write new code** — implement features, functions, classes, and modules from scratch
- **Refactor existing code** — improve structure, readability, and performance
- **Fix bugs** — identify and resolve issues in your codebase
- **Add tests** — create unit, integration, and end-to-end tests

### 🔍 Code Understanding
- **Explain code** — describe what existing code does and how it works
- **Review pull requests** — analyze changes and provide feedback
- **Trace logic** — follow execution paths and data flows across files

### 📦 Dependency & Config Management
- **Update dependencies** — safely bump library versions
- **Configure tools** — set up linters, formatters, build systems, and CI pipelines
- **Generate configuration files** — create `.gitignore`, `Dockerfile`, `package.json`, etc.

### 🔒 Security
- **Scan for vulnerabilities** — detect insecure code patterns
- **Fix security issues** — address common vulnerabilities (XSS, SQL injection, etc.)
- **Review secrets exposure** — flag accidentally committed credentials

### 📄 Documentation
- **Write README files** — like this one!
- **Generate API docs** — document functions, classes, and endpoints
- **Update changelogs** — summarize what changed between versions

### 🚀 CI/CD & Workflows
- **Investigate CI failures** — read workflow logs and diagnose build/test failures
- **Fix failing pipelines** — correct misconfigurations and failing steps
- **Add GitHub Actions workflows** — automate testing, deployment, and more

---

> GitHub Copilot Coding Agent works best on focused, well-defined tasks with clear success criteria. Try opening an issue describing what you need and let it get to work!
